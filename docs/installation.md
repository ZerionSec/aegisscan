# Installation

## Requirements

- Python 3.8+
- `requests` library

## Quick Install

```bash
git clone https://github.com/ZerionSec/aegisscan.git
cd aegisscan
pip install -r requirements.txt
```

## Verify

```bash
python scanner.py --help
```

## Optional: Virtual Environment

```bash
python -m venv .venv
source .venv/bin/activate   # Linux/macOS
# or
.venv\Scripts\activate      # Windows
pip install -r requirements.txt
```
